# Tati Silva Nail Designer

Landing Page premium desenvolvida para fortalecer a presença digital da profissional Tati Silva Nail Designer, com foco em autoridade, experiência do usuário, responsividade e conversão de novos atendimentos via WhatsApp.

---

## Visão Geral

Este projeto foi desenvolvido utilizando uma abordagem **Mobile First**, priorizando uma experiência elegante, leve e responsiva em qualquer dispositivo.

O objetivo da landing é transmitir uma identidade visual premium, valorizando o trabalho da profissional através de uma navegação fluida, tipografia refinada, imagens de alta qualidade e uma jornada de conversão simples e objetiva.

---

## Tecnologias

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Firebase (estrutura preparada para futuras integrações)

---

## Funcionalidades

- Header fixo com navegação por âncoras
- Hero responsivo (Desktop, Tablet e Mobile)
- Layout totalmente responsivo
- Seção de diferenciais
- Apresentação da profissional
- Catálogo de serviços
- Galeria premium de trabalhos
- Seção de avaliações das clientes
- Localização e horário de atendimento
- Footer institucional
- Botão flutuante para WhatsApp
- SEO básico
- Estrutura preparada para expansão

## Como executar o projeto

Instale as dependências:

```bash
npm install
```

Execute o ambiente de desenvolvimento:

```bash
npm run dev
```

Acesse:

```text
http://localhost:3000
```
